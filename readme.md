# 3D Portfolio Website

An interactive portfolio website built with Three.js, React, TypeScript, and Webpack.

To set up a development environment:

```bash
# Clone the repository

# Install dependencies
npm install

# Run the local dev server
npm run dev
```

To create a production build:

```bash
npm run build
```

The production files are generated in `public/` and can be deployed to any static web host.
